# Source release boundary

This is a new source-only snapshot of the project's previously private platform workspaces. Their operational histories remain private. Identical core/ trees were consolidated without changing engine rules.

Included: new Swift/Kotlin code, Python decoders, technical format notes, synthetic tests and an original compass icon.
Excluded: original game executables and archives, extracted/converted data, dialogue/map/music exports, original saves, build products, local test fixtures, signing keys, SDK paths and operational reports.

All platforms exclude game-data resources by default. Explicit personal-build flags can bundle local data; those outputs must remain private. A clean source checkout does not prove game completeness. Mobile phone layouts are plans, and actual iPad/Android device builds need their own toolchains and data.
